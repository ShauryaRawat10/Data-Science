## Introduction to Databases:

#### Problems: Chaos without organization
- Data Overload
- Errors and Duplicates
- Time consuming searches
- Difficult Updates


#### Database
- A database is organized collection of structured information or data, stored electronically in computer system
  - Structured storage: Tables
  - Easy retrieval
  - Data Integrity: accuracy and consistency
  - Scalability

#### Basic Database Concepts
- Data is stored in tables, like spreadsheets
- Each table has rows (records) and columns (fields)
- Queries are used as valid instructions to fetch, update, insert and modify the data
  - Tables
  - Queries
  - Relationships
  - DBMS: Software layer that manages the databases
 - DBMS Examples: SQLite, MySQL, Oracle

#### ER Diagram
- Entity Relationship diagram containing tables, relationships and fields along with their data types/size

#### Between clause
- The BETWEEN clause returns the result set which contains all the values matching the specified range, including the upper and lower limit.
- E.g. SELECT * FROM EMPLOYEES WHERE SALARY BETWEEN 1000 and 5000 returns all the employees whose salary is >=1000 and <=5000


#### SQL Built-in functions
```
- Quotient and Remainder

Select 27 div 7 as quotient;  -> 3

Select 27 MOD 7 as remainder;  -> 6
```

```
- Ceil and floor

Select CEIL(57.0001) CIEL_1, CEIL(57.898) CIEL_2;  -> 58, 58
Select FLOOR(57.0001) FLOOR_1, FLOOR(57.898) FLOOR_2;  -> 57, 57

Select TRUNCATE(57.4982, 2) TRUNCATE_1 -> 57.49
```

#### SQL Date and Time Functions

```
- Current Date and Time
SELECT NOW();
SELECT DATE('now') ;

- Current Date
SELECT CURDATE();

- Current Time
SELCT CURTIME()

- Number of days between 2 dates
SELECT DATEDIFF(CURDATE() , '2020-01-01');

- Add dates
SELECT DATE_ADD(CURDATE(), INTERVAL 10 DAY);

- Find day, month, year of date
SELECT DAY(CURDATE()), MONTH(CURDATE()), YEAR(CURDATE()) ; -> 8, 4, 2025

- Find Day Name
SELECT DAYNAME(CURDATE());

- Find day of year for a date
SELECT DAYOFYEAR(CURDATE()) -> 96

SELECT DAYOFWEEK(CURDATE()); -> 3

SELECT LAST_DAY(CURDATE()); -> 2025-08-30

- Format date
SELECT DATE_FORMAT(CURDATE(), '%d-%b-%Y') AS NEW_DATE;  -> 08-APR-2025
SELECT DATE_FORMAT(CURDATE(), '%D-%m-%y') AS NEW_DATE;  -> 8th-04-25
SELECT DATE_FORMAT(CURDATE(), 'The %D of %b, %Y') AS NEW_DATE;  -> The 8th of Apr, 2025

- String to date
SELECT STR_TO_DATE('12,10,2022', ''%d,%m,%Y') -> 2025-10-12 (defualt format of date in sql)
```

```

- Julian days
julianday() function, which returns the number of days since noon on November 24, 4714 B.C. in the Gregorian calendar (the start of the Julian date calendar). It returns a floating-point number.
Commonly used in SQL functions to find difference between dates
SELECT 
	ORDER_ID,
	ROUND(JULIANDAY('now')-JULIANDAY(ORDER_DATE)) AS DAYS_SINCE_ORDER
FROM ORDERS ;

```
