## Introduction to Databases:

#### Problems: Chaos without organization
- Data Overload
- Errors and Duplicates
- Time consuming searches
- Difficult Updates


#### Database
- A database is organized collection of structured information or data, stored electronically in computer system
  - Structured storage: Tables
  - Easy retrieval
  - Data Integrity: accuracy and consistency
  - Scalability

#### Basic Database Concepts
- Data is stored in tables, like spreadsheets
- Each table has rows (records) and columns (fields)
- Queries are used as valid instructions to fetch, update, insert and modify the data
  - Tables
  - Queries
  - Relationships
  - DBMS: Software layer that manages the databases
 - DBMS Examples: SQLite, MySQL, Oracle

#### ER Diagram
- Entity Relationship diagram containing tables, relationships and fields along with their data types/size

#### Fatching data in SQL

USE ORDERS;

```
Fetch details of customer whose FirstName contains 'B' as 3rd character and ends with 'S'
Select * from customers where firstname like __B%S
```

#### Between clause
- The BETWEEN clause returns the result set which contains all the values matching the specified range, including the upper and lower limit.
- E.g. SELECT * FROM EMPLOYEES WHERE SALARY BETWEEN 1000 and 5000 returns all the employees whose salary is >=1000 and <=5000
