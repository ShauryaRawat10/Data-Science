#### Windows Functions

- SQL window functions perform calculations across a set of rows related to the current row, called a "window," without collapsing them like aggregate functions
- Apply when analytical computations across subsets of data is needed


```
- Row_Number() Function
SELECT
	PRODUCT_NAME,
	PRODUCT_PRICE,
	PRODUCT_CLASS,
	ROW_NUMBER() OVER() AS ROW_NUM
FROM PRODUCT ;

SELECT
	PRODUCT_NAME,
	PRODUCT_PRICE,
	PRODUCT_CLASS,
	ROW_NUMBER() OVER(
		PARTITION BY PRODUCT_CLASS
		ORDER BY PRODUCT_PRICE ASC) AS ROW_NUM
FROM PRODUCT ;
```

```
- Rank() Function
SELECT 
    PRODUCT_NAME, 
	RANK() OVER(
		PARTITION BY PRODUCT_CLASS
		ORDER BY PRODUCT_PRICE DESC) AS RNK
FROM 
	PRODUCT ;
```

```
- LEAD() vs LAG()

- Find next order date, and number of days between each order
Select Order_Id, Order_Date, 
LEAD(Order_Date) OVER(ORDER BY Order_Date ASC) AS NEXT_ORDER_DATE,
JULIANDAY(Order_Date) - JULIANDAY( LEAD(Order_Date) OVER(ORDER BY Order_Date ASC) ) AS DAYS_BETWEEN
from Orders 
where customer_id = 11  

```

#### ORDER OF EXECUTION IN SQL
- Important to optimize query performance
- 1. FROM
- 2. WHERE
- 3. GROUP BY
- 4. HAVING
- 5. SELECT
- 6. ORDER BY
- 7. LIMIT

```
- Order of execution
SELECT 
	C.CUSTOMER_ID, 
	C.CUSTOMER_FNAME, 
	C.CUSTOMER_LNAME, 
	SUM(O.PRODUCT_QUANTITY * P.PRODUCT_PRICE) AS TOTAL_SPENT, 
	RANK() OVER(ORDER BY SUM(O.PRODUCT_QUANTITY * P.PRODUCT_PRICE) DESC) AS RNK 
FROM 
	CUSTOMER C 
	JOIN ORDERS O 
		USING(CUSTOMER_ID) 
	JOIN PRODUCT P 
		USING(PRODUCT_ID) 
WHERE 
	DATE(O.ORDER_DATE) > DATE('2024-01-01') 
GROUP BY 
	C.CUSTOMER_ID 
HAVING 
	SUM(O.PRODUCT_QUANTITY * P.PRODUCT_PRICE) > 0 
ORDER BY 
	TOTAL_SPENT DESC
LIMIT 2;
```
