## MLOps Components and Principles

#### MLOps Components
- MLOps is a set of practice that help bring machine learning models to production in a scalable and efficient way

```
ML Code:
- Data Collection
- Data Verification
- Feature Engineering
- Configuration
- Automation
- Testing and Debugging
- Resource management
- Model analysis
- Process management
- Metadata management
- Monitoring
- Service Infrastructure

Minimal Set of Tools for MLOps:
- Version Control: GitLab, GitHub, Azure DevOps
- CICD: GitHub Actions, Azure Pipelines, Jenkins
- Orchestration: Airflow, AWS Step Functions, Databricks Workflows
- Model Registry: MLflow, Comet ML
- Container Registry: ACR, ECR, Docker Hub
- Compute: Kubernetes jobs, Databricks Jobs
- Serving: Databricks serving, Sagemaker endpoints, kebernetes
- Monitoring: ELK stack, Prometheus, Grafana
- Data Version Control: DVC, Delta Tables

Other MLOPs components:
- Feature Store: Feast, Tecton, Databricks
- Labeling: Labelbox, Scale AI
- Experimental Tracking: MLflow, neptune.ai, Weights and Biases
- Responsible AI: Arthur, Guardrails AI, Fiddler AI
- Vector database: Pinecone, Weaviate, Qdrant
- LLM Evaluation: Langcheck, HoneyHive
- LLM Frameworks: Langchain, LlanaIndex, AdalFlow
- Model Hub: Hugging Face, Amazon Bedrock, Databricks
```
